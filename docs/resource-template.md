# 育兒資源清單模板

這份模板可用來整理、分類與後續匯入資源資料。

## 資源基本資訊

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| 資源名稱 | 資源的正式名稱 | 新生兒睡眠基礎指南 |
| 連結 | 資源的原始連結 | https://example.com/sleep |
| 摘要 | 簡短說明資源內容 | 介紹新生兒睡眠節律與安全睡眠做法 |
| 內容類型 | 資源呈現形式 | 文章 / 影片 / 工具／用品 / 混合型內容 / 連結入口 |
| 提供方／來源類型 | 資源來源類型 | 政府 / 醫院 / 社團 / 個人創作者 / 其他 |
| 原始來源 | 實際發布者或網站名稱 | Parenting Blog |
| 是否為入口型資源 | 是否為多資源匯聚頁 | 是 / 否 |

## 分類欄位

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| 年齡階段 | 最適合的孩子發展階段 | 0–1歲 |
| 主題 | 資源主要關注的育兒需求 | 睡眠 |
| 關鍵標籤 | 可用於搜尋或補充分類的標籤 | 新生兒、安撫 |
| 年齡群組 | 搜尋用的教育階段分類 | 學齡前 / 國小 / 國中 / 高中 / 全齡 |
| 地區 | 資源適用的地理範圍 | 全國 / 縣市 / 鄉鎮 |
| 資源類型 | 資源的服務或內容分類 | 學習教材 / 課程 / 活動 / 補助 / 政策 / 機構 |
| 使用對象 | 主要使用者 | 兒童 / 家長 / 教師 / 學校 |
| 來源地區 | 資源發布者所在國家或地區 | 台灣 |
| 語言 | 資源提供的語言 | 繁體中文 |

## 信任與審核資訊

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| 審核狀態 | 是否已完成人工核實 | AI 整理・待人工核實 / 人工核實 |
| 可信度備註 | 可補充來源可信度說明 | 政府機構發布 |
