Before exploring, read root `CONTEXT.md` when present and relevant ADRs under `docs/adr/`. Missing domain files are allowed and should not block work.

## Layout

This is a single-context repository: domain vocabulary belongs in root `CONTEXT.md`, and architectural decisions belong in `docs/adr/`.

Use glossary vocabulary in issues, proposals, hypotheses, and tests. Surface conflicts with existing ADRs explicitly rather than silently overriding them.
