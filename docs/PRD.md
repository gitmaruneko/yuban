專案一句話目標
- 成為陪伴父母育兒的整合資源平台：一站式找到教學、影片、用品指南與父母心得。

目標使用者
- 有小孩的父母（孕期至學齡前家長），希望快速取得可信且實用的育兒資源。

關鍵 KPI（含數值與時程）
- MAU：6 個月內達 1,000；12 個月達 3,000。
- 資源覆蓋：6 個月內建立 300 筆已分類資源（含影片、文章、工具、商品指南）。
- 使用者滿意度：6 個月內問卷平均 ≥ 4.0 / 5。

MVP 範圍（2 週交付）
- 必要功能：
  - 靜態前端站（`website/`）與響應式首頁
  - 資源索引資料（`website/data/sample-resources.json`）與資源詳情頁
  - 客戶端搜尋/篩選（按年齡、主題、來源）使用 `Lunr.js` 或 `fuse.js`
  - 簡易回報/提交表單（Google Form / 網頁表單）以收集新資源
  - 明確來源標示與「AI 摘要 / 已驗證」標籤
- 非必要（推後）：帳號系統、原生評論系統、成長曲線工具、付費牆。

時程與里程碑
- 2026-08-12（兩週內）: MVP 上線（靜態站 + 30 筆示例資源）。
- 2026-10-01（1.5 個月後）: 收集早期使用者回饋並完成首輪內容擴充（達 150 筆）。
- 2027-01-29（6 個月）: 完整版本目標（評論功能、基礎使用者帳號、輕量資料庫或 Supabase 整合、成長曲線雛形）。

重要假設與驗證計畫
- 假設 A：父母會使用統整型資源站。
  - 驗證：部署簡易 landing + 分享到社群，觀察訪客、訂閱率與回饋（2 週內）。
- 假設 B：AI 摘要能提升整理速度且準確度可接受。
  - 驗證：產出 50 篇 AI 摘要、抽樣人工核查；若錯誤率 > 20% 則增加人工把關流程。
- 假設 C：簡易評論/心得能提高黏著度。
  - 驗證：MVP 先用第三方評論或表單觀察互動率，KPI：評論轉換率 ≥ 5%。

主要風險與緩解
- 內容可信度不足 → 顯示來源與審核狀態、AI+人工雙層檢查。
- 維運人力不足 → 自動化流程（AI 摘要 + 一鍵建檔）、招募志工/家長協助審核。
- 曝光成長緩慢 → SEO、與育兒社群/診所合作、製作可分享卡片。
