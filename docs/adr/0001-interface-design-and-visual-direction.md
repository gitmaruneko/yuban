# ADR-0001: Interface Design and Visual Direction

- Status: Accepted
- Date: 2026-07-29

## Context

育伴的主要使用者會在手機與零碎時間中快速查找育兒資訊。介面除了提高搜尋效率，也必須讓使用者在開啟原始來源前理解內容的適用性與審核狀態。既有通用藍白卡片原型無法表達育兒品牌或可信度層級。

## Decision

介面採「可信而溫暖」的現代育兒編輯部風格，並以手機快速查找為主要情境。

- 品牌顯示為「育伴 YuBan」。
- 首屏包含簡短品牌承諾、主要搜尋框與年齡快捷篩選，並露出第一批資源。
- 視覺以墨色、葉綠、珊瑚色與明亮中性色建立層次，避免幼兒化或醫療機構感。
- 策展與品牌標題使用明體，介面文字與內容使用清晰黑體。
- 使用少量能呈現真實家庭或用品情境的策展照片；搜尋結果不強制配置圖片。
- 資源卡緊湊呈現標題、短摘要、來源、審核狀態、年齡與主題。
- 審核狀態使用「AI 整理・待人工核實」與「人工核實」，原始來源始終可見。
- 手機版直接顯示年齡篩選，主題與來源收納於更多篩選面板。
- 點擊資源先進入育伴詳情，再由明確命令前往原始來源。
- 全站使用精簡黏性頁首，提供探索與提交資源入口。
- 提交資源先顯示站內說明，再銜接第三方表單。
- 動態效果克制且服務於載入、篩選和狀態變化，並尊重 reduced-motion 設定。

## Consequences

- 首頁不是大型行銷 landing page，也不是童趣娛樂介面。
- 搜尋與篩選效率優先於大量品牌敘事或圖像卡片。
- 實作需要補齊資源詳情、主題與來源篩選、可信度說明及提交入口。
- 圖像素材必須與內容直接相關且品質一致；缺少合適素材時以資訊排版為主。
- 帳號、原生評論、成長工具與付費牆維持在 MVP 範圍之外。
